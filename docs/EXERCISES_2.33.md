# Exercises 2.33

Exercises uses a compact shelf of twelve lessons in three groups: Foundations, Reading & rhythm, and Chords & coordination. Selection keeps the lesson cards in place on desktop and updates one practice card. The card contains the lesson focus, a small handmade musical illustration, genuine graded results and the Start action. The illustration is decorative and is not a preview of the randomly generated piece.

Hands and length are always available. Auto follows the selected level. Customize expands native key, meter and tempo controls; the current values remain visible when closed. Use level defaults clears all five overrides without changing the selected level. Existing overrides continue across level selection and navigation. A level with several default keys or meters picks its actual values when the new exercise is generated. The original tips remain under Level guide; early starting-position guidance adapts when a custom hand/key makes the original C-position tip inappropriate.

Start opens a new exercise paused in Practice. Double-click starts the clicked level explicitly. Exact seeds, MusicXML generation, saved exercises, reading preferences, graded history, recommendation and clearing rules remain. Every level stays available. Screen-reader card names include level, title, hand, best result and recommendation/clearing status. Native disclosures, selects and tempo drafts retain normal keyboard behavior.

The selected colour palette carries through cards and illustrations. Lesson changes use a brief opacity transition; reduced motion disables it. The companion button opens the existing conversation dock. A container-based layout reflows into the space available beside chat. On narrow windows, setup comes first visually and in the document/tab order, followed by the entire level shelf. The page scrolls normally, including short windows and expanded settings. The roaming companion protects the entire setup and guide; during scroll or disclosure reflow it tucks away until a clear seat is measured and reached. Header and app-bar chat buttons remain available.
